练习一：用户信息格式化
要求：
1. 定义两个变量 first_name 和 last_name，分别赋值为你的拼音（例如 "ada" 和 "lovelace"）。
2. 使用 f-字符串 将这两个变量拼接为全名，并赋值给 full_name 变量。
3. 使用字符串的 title() 方法，将 full_name 的首字母大写，并加上一句问候语 "Hello, [格式化后的全名]!" 打印出来。
4. 假设变量 raw_name = "  iTuring  "（前后有空格），请分别使用 lstrip()、rstrip() 和 strip() 处理该字符串，并打印三次结果，观察空白字符的变化。

练习二：数字与字符串的魔法运算
要求：
1. 同时给三个变量 x, y, z 赋值：x = 3，y = 4，z = 2。
2. 计算 x 的 z 次方（乘方），并赋值给变量 result_power。
3. 计算 y 除以 z 的整数除法，并赋值给变量 result_division。
4. 使用 f-字符串 打印出以下格式的文本：
   “3的2次方是：[result_power]”
   “4整除2的结果是：[result_division]”
5. 结合字符串拼接操作（+ 或 *），用 print 打印出一行由 3 个 "Python " 组成的字符串（注意末尾不需要多余空格）。
